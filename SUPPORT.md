# Support

Use the channel that matches the request:

- Questions and usage help: use the
  [question form](https://github.com/vvka-141/pgmi/issues/new?template=question.yml).
- Reproducible defects: use the
  [bug report form](https://github.com/vvka-141/pgmi/issues/new?template=bug.yml).
- Product ideas: use the
  [feature request form](https://github.com/vvka-141/pgmi/issues/new?template=feature.yml).
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and use private
  vulnerability reporting.
- Conduct incidents: follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and use the
  same private reporting channel with `Code of Conduct` in the title.

Before opening an issue, search existing issues and check the
[documentation](docs/README.md). Include the pgmi version, PostgreSQL version,
operating system, exact command, and sanitized output when they are relevant.
