These SVGs are official brand marks used **referentially** in architecture
diagrams to identify the external products they represent. All trademarks
belong to their respective owners; no endorsement is implied.

| File | Mark | Owner / policy |
|------|------|----------------|
| `postgresql.svg` | PostgreSQL elephant (Slonik) | [PostgreSQL trademark policy](https://www.postgresql.org/about/policies/trademarks/) |
| `azure.svg` | Microsoft Azure | Microsoft trademark & brand guidelines |
| `aws.svg` | Amazon Web Services | AWS trademark guidelines |
| `gcp.svg` | Google Cloud | Google brand permissions |
| `github.svg` | GitHub Invertocat (Octicons mark, MIT) | GitHub logo usage policy |
| `docker.svg` | Docker | Docker brand guidelines |

Sourced from Wikimedia Commons. If any owner objects to a usage, remove the
mark and fall back to the house-style icons in the parent directory.
