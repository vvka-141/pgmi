# 0013: Reading and editing pgmi.yaml

Status: proposed, 2026-11-10. Ticket: PGMI-829.
Checked on crates.io / docs.rs, 2026-11-10: serde-saphyr 2.1.1 (2026-11-05,
strict typed deserializer, no unsafe code, fuzz-tested parser), yaml-edit
0.3.6 (2026-10-31, lossless rowan tree, "error recovery: continues parsing
even with syntax errors"), saphyr 0.3.3, serde_yaml_ng 0.10.0 (last release
2024-05).

## Context

pgmi reads `pgmi.yaml` (`connection`, `params`, `timeout`; an unknown key is
exit 10) and renders param values as text: `~` is empty, numbers and booleans
exactly as written (`5432.0` stays `5432.0`), block scalars keep their final
newline. The `config` wizard rewrites the connection settings and must keep
the file's comments, other keys and inline comments.

## Options

- **Reading**: serde-saphyr (strict, typed, maintained), serde_yaml_ng
  (stale), or yaml-edit for reading too (one library, but it parses
  leniently by design, so a broken file would not be refused).
- **Editing**: yaml-edit (built for exactly this), or pgmi's own text
  surgery on the `connection:` block (small, but breaks on flow style,
  anchors or odd indentation).

## Decision

serde-saphyr to read, yaml-edit to edit.

- Reading into a struct with `deny_unknown_fields` at every level. Param
  values are deserialized through a visitor that keeps the scalar's source
  text (`Option<String>`; null becomes empty), so `5432.0`, `007` and `true`
  arrive as written. To be confirmed with `formats/pgmi-yaml-edges` on the
  first build; if serde-saphyr resolves plain scalars before the visitor
  sees them, read params with saphyr's event parser instead.
- Editing: the wizard loads the file into a yaml-edit `Document`, sets the
  keys under `connection`, and writes it back. A file serde-saphyr refuses is
  only replaced after the explicit confirmation the docs describe. A new
  file is written from a fixed text.
- Every write goes to a temporary file in the same folder, then a rename.

## Consequences

- Two YAML crates. yaml-edit is young (0.3, low downloads); it is only on
  the wizard path, and `terminal/config-wizard` pins what it must keep.

## Serves

File formats; config; Parameters; Connection sources (`pgmi.yaml`).
